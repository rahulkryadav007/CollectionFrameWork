# 02 — Queue & Deque

- `Queue`: commonly processes elements in FIFO order.
- `Deque`: supports insertion/removal at both ends; useful for queues and stacks.
- `PriorityQueue`: retrieves elements according to priority (natural order or comparator), not insertion order.
- `ArrayDeque`: efficient general-purpose deque; does not permit null elements.

Practice: `offer`, `poll`, `peek`, `add`, `remove`, `element`, `offerFirst`, `offerLast`, `pollFirst`, `pollLast`.

DSA applications: BFS, task scheduling, sliding-window maximum, stack/queue simulation, top-K problems.
