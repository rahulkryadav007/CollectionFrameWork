# 05 — Iteration & Utilities

Learn how to traverse and manipulate collections safely and clearly.

- Enhanced `for` loop, `Iterator`, and `ListIterator`
- `Collections.sort`, `reverse`, `shuffle`, `min`, `max`, `frequency`, `binarySearch`
- `Collections.unmodifiableList` and immutable factory methods
- Convert between arrays and collections (`Arrays.asList`, `toArray`)
- Avoid structural modification during ordinary fail-fast iteration; use iterator removal or suitable concurrent collections where appropriate.

Remember: `Collection` is an interface; `Collections` is a utility class.
