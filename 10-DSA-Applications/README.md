# 10 — DSA Applications

Solve each problem in three stages: brute force → collections-based solution → complexity and edge-case review.

## Beginner
- Count frequencies with `HashMap`
- Remove duplicates with `HashSet`
- Find common elements of two arrays
- First non-repeating character

## Intermediate
- Two Sum using a map
- Group Anagrams
- Longest consecutive sequence
- Subarray sum equals K (prefix sum + map)
- Sliding-window frequency problems

## Advanced
- Top K frequent elements (`HashMap` + `PriorityQueue`)
- LRU Cache (`LinkedHashMap` or custom data structure)
- Sliding-window maximum (`Deque`)
- Median from data stream (two heaps)

For every problem, add: problem statement/link, intuition, commented Java solution, dry run, time/space complexity, and edge cases. Attempt each problem before viewing a solution.
