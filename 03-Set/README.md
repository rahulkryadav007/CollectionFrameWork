# 03 — Set

A `Set` models unique elements. Choose the implementation based on ordering and performance needs.

| Type | Behavior |
|---|---|
| `HashSet` | No guaranteed iteration order; hash-based |
| `LinkedHashSet` | Maintains insertion order |
| `TreeSet` | Sorted order; tree-based; elements use natural order or a Comparator |

Methods to practice: `add`, `remove`, `contains`, `size`, `isEmpty`, `clear`, `addAll`, `retainAll`, `removeAll`.

DSA applications: duplicate detection, membership checks, unique values, set intersection/union, visited nodes.
