# 01 — List

A `List` is an ordered collection that supports index-based access and usually allows duplicates.

## Lessons
- `ArrayList`: dynamic array, indexing, resizing, common methods
- `LinkedList`: node-based list; also implements `Deque`
- `Vector`: legacy synchronized list
- `Stack`: legacy LIFO class; prefer `Deque`/`ArrayDeque` for new stack code
- Traversal: enhanced `for`, `Iterator`, `ListIterator`
- Safe removal during iteration and sublists

## Suggested order
1. Run `ArrayList/ArrayListBasics.java`.
2. Practice `add`, `get`, `set`, `remove`, `contains`, `size`, `isEmpty`, `clear`, `indexOf`.
3. Compare ArrayList and LinkedList based on access pattern—not on a blanket claim that one is always faster.
4. Solve list-based DSA exercises.
